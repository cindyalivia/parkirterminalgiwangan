🚗 Giwangan Parking

Giwangan Parking adalah aplikasi berbasis web yang dibuat untuk membantu pengelolaan sistem parkir secara lebih mudah, cepat, dan terorganisir.

🌐 Demo Website

🔗 Website: https://giwanganparking.infinityfree.me

«Website di-host menggunakan InfinityFree.»

📌 Tentang Project

Giwangan Parking merupakan project pengembangan aplikasi berbasis web yang bertujuan untuk membantu proses pengelolaan data parkir, kendaraan, dan transaksi parkir.

Aplikasi ini dibuat sebagai project pembelajaran dalam bidang Rekayasa Perangkat Lunak (RPL) sekaligus sebagai penerapan teknologi web dalam permasalahan sehari-hari.

✨ Fitur

- 🔐 Login dan autentikasi pengguna
- 🚗 Pendataan kendaraan
- 🅿️ Pengelolaan data parkir
- 📝 Pencatatan kendaraan masuk dan keluar
- 💰 Pengelolaan transaksi parkir
- 📊 Dashboard informasi parkir
- 📋 Pengelolaan data secara terstruktur
- 📱 Tampilan yang dapat digunakan melalui browser

🛠️ Teknologi yang Digunakan

- HTML — Struktur halaman website
- CSS — Tampilan dan desain
- JavaScript — Interaksi pada halaman
- PHP — Pemrograman sisi server
- MySQL — Database
- XAMPP — Local development
- InfinityFree — Hosting website

⚙️ Cara Menjalankan di Localhost

1. Clone Repository

git clone https://github.com/username/giwangan-parking.git

2. Pindahkan Project

Letakkan folder project ke:

C:/xampp/htdocs/

3. Jalankan XAMPP

Aktifkan:

- Apache
- MySQL

4. Buat Database

Buat database melalui phpMyAdmin, kemudian import file database yang tersedia pada project.

5. Atur Konfigurasi Database

Sesuaikan konfigurasi koneksi database dengan database lokal, contohnya:

$host = "localhost";
$user = "root";
$password = "";
$database = "giwangan_parking";

6. Jalankan Website

Buka browser dan akses:

http://localhost/giwangan-parking/

5. Menjadi portofolio project siswa jurusan RPL.
